# Cycubix Docs

Welcome to the Cycubix documentation hub for application security, secure coding, technical labs, and hands-on training.

This site brings together practical guidance for developers, security engineers, and teams building safer web applications. It covers core concepts, OWASP Top 10 issues, secure coding patterns, tooling, and the exercises used in Cycubix training sessions.

## What you will find here

- secure coding guidance for Java and web applications
- OWASP Top 10 explanations and practical examples
- hands-on labs using WebGoat, WebWolf, and ZAP
- HTTP, proxy, browser, and developer tooling walkthroughs
- event and training resources connected to Cycubix learning programs

## Featured learning paths

### Secure coding fundamentals

Learn how to validate input, protect authentication flows, encode output, handle secrets safely, and defend common web application risks.

### OWASP Top 10 coverage

Use the OWASP Top 10 references to understand the most common high-impact weaknesses in web applications and how to prevent them in real systems.

### Practical labs

Work through exercises that simulate real-world vulnerabilities and their remediations using tools used in modern security training.
